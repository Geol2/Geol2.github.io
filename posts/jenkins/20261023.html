스프링 프로젝트의 개발서버를 Jenkins로 자동 확인하도록 세팅한 기록이다.

Job 구성

Job도구주기
API 스모크newman10분마다
화면 E2EPlaywright평일 1회
단위 테스트Maven + JUnit원격 저장소에 커밋이 있을 때

Jenkins 관리

  • Plugins : NodeJS, 원격 저장소용 SCM 플러그인, Credentials Binding
  • Tools
    • NodeJS installations : 버전 선택, Global npm packages 에 newman
    • Maven installations : Add Maven → Install automatically → Save
  • Credentials : 테스트 계정 비밀번호는 Secret text, 원격 저장소 계정은 Username with password

섹션설정

Build Steps

API 스모크

newman run smoke.postman_collection.json \
  -e dev.postman_environment.json \
  --env-var "password=$APP_PW" \
  -r cli,junit --reporter-junit-export results.xml

화면 E2E

npm ci
npx playwright install chromium
npx playwright test --workers=1

단위 테스트 (Windows 노드)

call mvn -B clean test -DskipTests=false

빌드 후 조치에 JUnit 리포트를 걸어두면 Job 화면에 테스트 결과 추이 그래프가 생긴다.
