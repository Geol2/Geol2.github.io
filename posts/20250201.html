Strang의 Linear Algebra를 공부하고 있고 선형대수학은 데이터 및 컴퓨팅 기반, 양자역학을 다루는 것에 더 적합하다.

또 다르게 미적분학이 항상 언급되는데 말그대로 물리학, 공학, 자연적인 변화와 움직임을 표현하는데에 적합하다. 결국 둘 다 상호보완적이다.

가우시안 소거법이 가장 먼저 언급되는 것 같고 처음 들어보는 낯선(?) 내용이였다.

가우시안 소거법은 행렬을 통해서 연립방정식을 풀어내는 방법이다. 일반적으로 배웠던 소거법이 가우시안 소거법을 간소화한 것이고 많은 데이터를 다뤄야할 땐 행렬을 이용한 방법이 효율적이다.

가우시안 소거법

가우시안 소거법에서 A=LU 분해를 이용하면 Ax=b 형태의 연립방정식을 풀어볼 수 있다.

A = L U

L : 하삼각행렬, U : 상삼각행렬

A = ( 12 45 )

해당 행렬을 Factorization 하면 다음과 같다.

( 12 45 ) = ( 10 41 ) ( 12 0-3 ) = L U

위처럼 Factorization 과정이 독특했는데, U(상삼각행렬)의 2행 1열을 0으로 만들기 위해 2행에서 1행의 4배를 빼준다. 이때 사용한 배수 4가 그대로 L의 2행 1열에 남는다.

4 - 4 ⋅ 1 = 0 , 5 - 4 ⋅ 2 = -3

소거에 쓴 연산을 행렬로 적으면 E ⋅ A = U 이고, 양변에 E의 역행렬을 곱하면 A = E-1U 가 된다. 이 E-1이 바로 L이므로 A = LU 가 성립한다.

이제 b를 하나 정해서 풀어보면, b = (3, 6) 일 때 Ly = b(전방대입)로 y를 구하고, Ux = y(후방대입)로 x를 구한다.

y = ( 3 , -6 ) ⇒ x = ( -1 , 2 )

3x3 행렬도 같은 방식이다. 다음 A를 소거해 U를 구해본다.

A = ( 21-1 -3-12 -212 )

소거는 한 번에 끝나지 않고, 0으로 만들 자리마다 소거행렬을 하나씩 곱해 나간다. 각 단계에서 쓰는 승수는 (없애려는 성분) ÷ (피벗) 이다.

1단계 : 승수 m21 = -3 ÷ 2 = -3/2 → 2행에서 1행의 (-3/2)배를 뺀다
2단계 : 승수 m31 = -2 ÷ 2 = -1 → 3행에서 1행의 (-1)배를 뺀다
3단계 : 승수 m32 = 2 ÷ (1/2) = 4 → 3행에서 2행의 4배를 뺀다

E32 E31 E21 A = U = ( 21-1 01212 00-1 )

여기서 재미있는 점은 L을 따로 계산할 필요가 없다는 것이다. 위에서 구한 승수 mij를 L의 (i, j) 자리에 그대로 적어 넣으면 된다.

A = L U = ( 100 -3210 -141 ) ( 21-1 01212 00-1 )

L의 대각선 아래가 (-3/2, -1, 4)로 승수와 정확히 일치한다. 소거하면서 기록만 해두면 L이 공짜로 따라오는 셈이다.

선형 방정식의 기하학

하나의 연립방정식을 읽는 방법은 두 가지다. 행 단위로 보는 관점(row picture)과 열 단위로 보는 관점(column picture)이고, 같은 식이라도 머릿속에 그려지는 그림이 전혀 다르다.

행 그림 (Row Picture)

다음 연립방정식을 보자.

2x-y=1 x+y=5

각 방정식을 xy 평면 위의 직선 하나로 본다. 첫 식은 기울기 2인 직선, 둘째 식은 기울기 -1인 직선이다. 연립방정식의 해는 두 직선이 만나는 점이고 여기서는 (2, 3) 이다. 행렬로 적으면 A의 각 행이 직선 하나에 대응한다.

열 그림 (Column Picture)

같은 식을 열 기준으로 묶으면 모양이 달라진다.

x ( 2 1 ) + y ( -1 1 ) = ( 1 5 )

이제 문제가 두 직선의 교점을 찾는 것에서 두 벡터를 어떤 비율로 섞으면 b가 되는가로 바뀐다. x = 2, y = 3 을 넣어보면 실제로 b가 나온다.

2 ( 2 1 ) + 3 ( -1 1 ) = ( 4 2 ) + ( -3 3 ) = ( 1 5 )

즉 Ax는 A의 열벡터들의 선형결합(linear combination)이고, Ax = b 는 b가 A의 열들로 만들 수 있는 것인지를 묻는 질문이다.

왜 열 그림이 중요한가

행 그림은 2차원에서 직선, 3차원에서 평면이라 눈으로 그릴 수 있지만 차원이 커지면 그릴 수 없다. 반면 열 그림의 선형결합이라는 개념은 차원과 무관하게 그대로 확장된다. 뒤에 나오는 열공간, 계수(rank), 기저 같은 개념이 전부 이 관점에서 출발한다. Strang이 열 그림을 반복해서 강조하는 이유가 여기 있다.

3x3 — 평면 세 개

앞에서 LU 분해한 A에 b = (1, 1, 6) 을 주면 해는 (1, 2, 3) 이다.

행 그림으로는 3차원 공간에 평면이 세 개 놓인 모습이고, 세 평면이 한 점에서 만나면 그 점이 유일한 해다. 열 그림으로는 세 열벡터를 1 : 2 : 3 으로 섞어 b를 만드는 문제가 된다.

1 ( 2 -3 -2 ) + 2 ( 1 -1 1 ) + 3 ( -1 2 2 ) = ( 1 1 6 )

같은 답을 앞의 LU로도 구할 수 있다. Ly = b 를 전방대입하면 y = (1, 5/2, -3) 이고, Ux = y 를 후방대입하면 x = (1, 2, 3) 이다. 기하학적으로 세 평면의 교점으로 본 답과 대수적으로 소거법으로 푼 답이 같다는 것을 확인할 수 있다.

해가 하나가 아닌 경우

두 개의 연립방정식이라도 행렬로 표현된 방정식의 그래프가 다르게 표현될 수 있다는 것이 이 부분이다. 다음 두 경우를 비교해보자.

x+2y=3 2x+4y=6 x+2y=3 2x+4y=7

왼쪽은 둘째 식이 첫 식의 정확히 2배다. 두 직선이 완전히 겹치므로 해가 무수히 많다. 오른쪽은 좌변만 2배이고 우변이 맞지 않는다. 두 직선이 평행해서 만나지 않으므로 해가 없다.

열 그림으로 보면 두 경우의 차이가 더 분명해진다. 두 열 (1, 2)와 (2, 4)는 서로 평행해서, 아무리 섞어도 평면 전체가 아니라 직선 하나밖에 만들지 못한다.

b = (3, 6) → 그 직선 위에 있다 → 해가 존재하고 무수히 많다
b = (3, 7) → 그 직선 위에 없다 → 해가 없다

소거법에서는 이것이 피벗으로 드러난다. 2행에서 1행의 2배를 빼면 둘째 행이 (0 0 | 0) 또는 (0 0 | 1)이 되어 두 번째 피벗이 0이 된다. 이렇게 피벗이 0으로 떨어지는 행렬을 특이행렬(singular matrix)이라 하고, 이때 A는 역행렬을 갖지 못한다. 앞선 예제들이 문제없이 풀렸던 것은 피벗이 모두 0이 아니었기 때문이다.

3x3 에서는 평면 세 개가 놓이는 방식이 더 다양하다.

· 한 점에서 만남 → 유일한 해 (비특이)
· 한 직선을 공유 → 해가 무수히 많음
· 평면끼리는 만나지만 세 평면의 공통점이 없음 (삼각기둥 모양) → 해가 없음
· 두 평면 이상이 평행 → 해가 없음

뒤의 세 경우는 모두 소거 과정에서 피벗 하나가 0이 되는 것으로 나타난다. 결국 그래프가 어떻게 놓이는가라는 기하학적 질문과 피벗이 0이 되는가라는 대수적 질문이 같은 것을 보고 있는 셈이다.
